# 项目级图片处理

用户已确认后台并发下载结束后一次插入。配置保存到项目，提供保留链接（默认）、下载本地、Base64 三种模式。下载目录支持绝对路径、以项目为基准的相对路径及 ${ProjectPath}；输出链接以 Markdown 所在目录为基准。

以 SHA-256 为文件指纹，在下载目录维护 JSON 指纹到相对文件路径映射。下载并行，文件提交与映射重建互斥，映射原子写入。重建递归扫描普通文件，排除映射及临时文件，不删除重复内容。失败保留原链接并汇总提示。下载任务可取消；编辑器内容在任务期间变化时不覆盖已有修改。

范围包括 Markdown 图片与表格 HTML img；不下载代码片段里的图片示例。配置页提供手动重建按钮，重建在后台运行。
